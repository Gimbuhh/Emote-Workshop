# Emote Workshop 1.4

## Added

- Paste a public Twitter/X post into **Import media** to edit its GIF or video and export an animation for your destination. Start the local app with `npm run dev` and open `http://127.0.0.1:4173` for post links. GIF attachments are preferred, the best available MP4 is downloaded, and attachment suffixes select a specific item.
- Paste a direct `video.twimg.com` MP4 link in either the local app or the standalone HTML file. Downloads are limited to 100 MB and 30 seconds. If a post is private, deleted, restricted, or missing media in its public embed, use a direct MP4 link or browse for a saved file.

Twitter's GIFs arrive as MP4. Export Twitch emotes or Discord emoji as GIF, or select **GIF** in the 7TV export format menu. Processing stays on your device.

Public post import requires the local server. The standalone download and static hosted editor accept direct MP4 links; this release does not add a hosted post resolver.

Package version: `1.4.0`; Git tag: `v1.4`.
