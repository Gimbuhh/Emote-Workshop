# Emote Workshop 1.4

## Added

- Paste a public Twitter/X post into **Import media** on the website or in the standalone HTML file to edit its GIF or video and export an animation for your destination. No local server is needed. GIF attachments are preferred, the best available MP4 is downloaded, and attachment suffixes select a specific item.
- Paste a direct `video.twimg.com` MP4 link in either the local app or the standalone HTML file. Downloads are limited to 100 MB and 30 seconds. If a post is private, deleted, restricted, or missing media in its public embed, use a direct MP4 link or browse for a saved file.

Twitter's GIFs arrive as MP4. Export Twitch emotes or Discord emoji as GIF, or select **GIF** in the 7TV export format menu. Processing stays on your device.

Public post links need an internet connection and use the hosted Emote Workshop service to find the MP4 URL. The service receives only the public post ID and optional attachment number. Your browser downloads media directly from Twitter and processes it locally. Direct MP4 links bypass the service, and saved-file imports work offline. Developers can still use `npm run dev` for the local resolver.

Package version: `1.4.0`; Git tag: `v1.4`.
