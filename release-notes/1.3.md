# Emote Workshop 1.3

## Added

- **Import media** now accepts 7TV emote page and CDN links. It downloads a selected 1x–4x rendition before opening it in the editor, using 4x AVIF by default with WebP, GIF, and PNG options.
- Large animated imports decode frames in bounded parallel batches and show progress while decoding and checking transparency.
- 7TV export now prefers AVIF and offers WebP and GIF choices. When the browser cannot encode animated AVIF, the editor falls back to animated WebP and then GIF and labels the produced format.

## Changed

- Discord and Twitch exports can keep animations longer than five seconds when they fit. Longer selections are sampled and palette-optimized only as needed for the destination's file-size and frame-count limits.

## Fixed

- Centered the plus badge in the empty import control.
- Replaced the file-name field's wide double focus border with a cleaner contained focus ring.
- Added breathing room and rounded edges to the hover and active surfaces of **Keep canvas filled** and the transparent-margin toggle.
- Started imported animation playback immediately after decoding and kept it continuous when export previews finish preparing.
- Kept the canvas playback control at a stable width so **Compare** no longer shifts when toggling Play/Pause.
- Compressed Discord sticker animations with filtered APNG delta frames, allowing many full-size 320×320 stickers to fit without shortening their playback.

## Security

- Immediate animation previews now use format-validated media reconstructed by the background decoder rather than a URL derived directly from the selected file.

Package version: `1.3.0`; Git tag: `v1.3`.
