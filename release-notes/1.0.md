## Added

- An offline, self-contained HTML editor for Twitch emotes, Discord emoji and stickers, and 7TV emotes. Open `Emote Workshop.html` in Chrome or Edge without installing the app or running a server.
- Import PNG, JPEG, GIF, WebP, AVIF, or MP4 media, including supported animated sources, by file selection, drag/drop, or image paste. A sample image is included.
- Independent framing and undo/redo for each destination: drag and keyboard positioning, center snapping, Scale, Width/Height stretching from 100–300%, rotation, flip, fit/fill, transparent-margin trimming, outlines, and brightness. Numeric fields support exact values and individual resets.
- Animation start/end trimming with a thumbnail filmstrip, playback controls, and speed adjustment from 50–150%.
- Dark/light chat previews and validated exports: Twitch packs at 112/56/28 pixels, Discord emoji at 128 pixels, Discord stickers at 320 pixels, and aspect-ratio-preserving 7TV uploads within 1000 × 1000 pixels and 7 MB.
- PNG output for still sources, GIF for animated Twitch/Discord emoji/7TV sources, and APNG for animated Discord stickers. Current-destination downloads and an all-destinations ZIP are available.
- Deterministic offline packaging and automated syntax, formatting, media, and browser checks.

## Notes

- Package version: `1.0.0`; Git tag: `1.0`; version commit date: 2026-09-17.
- Media processing stays local. Browser media API support is required for animation/video decoding and some output formats.
- Twitch/Discord animation selections are limited to five seconds; 7TV has no five-second cap. Large or animated sources may be sampled, and encoding may reduce frames or color detail to meet upload limits.
