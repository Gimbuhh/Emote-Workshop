## Added

- Scroll while hovering over the image framing canvas to zoom: scrolling up increases Scale by one percentage point; scrolling down decreases it by one percentage point. Each vertical wheel event applies one step regardless of its delta magnitude.
- Wheel zoom stays within the existing 10–300% Scale range, updates the Scale slider and numeric field, redraws the editor, and refreshes output previews.
- Zoom changes use the existing per-destination settings and undo/redo history. Scrolling beyond a limit does not add an unchanged history entry.
- Canvas instructions and accessible text describe scroll zoom. Regression tests cover the authored page and the standalone HTML edition.
- A visible `v1.1.0` version link beside the Emote Workshop title in the header, opening the project's changelog on GitHub in a new tab.
- A root changelog and per-version release notes, following the release-notes folder structure.

## Notes

- Package version: `1.1.0`; Git tag: `v1.1`; version commit date: 2026-09-17.
- Wheel zoom is unavailable while media is being imported or exported. Horizontal-only scroll events and Ctrl/Command-modified scroll gestures are left to the browser.
- Scrolling outside the image framing canvas does not change Scale.
