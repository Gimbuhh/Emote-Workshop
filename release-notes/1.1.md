## Added

- Scroll while hovering over the image framing canvas to zoom. Scrolling up increases Scale by one percentage point and scrolling down decreases it by one percentage point.
- Wheel zoom follows the existing 10–300% Scale limits, refreshes the editor and output previews, and participates in each destination's undo/redo history.
- Canvas instructions and accessible text now describe the scroll-to-zoom control.

## Notes

- Package version: `1.1.0`; Git tag: `v1.1`; version commit date: 2026-09-17.
- Wheel zoom is unavailable while media is being imported or exported. Horizontal-only scroll events and Ctrl/Command-modified scroll gestures are left to the browser.
- Scrolling outside the image framing canvas does not change Scale.
