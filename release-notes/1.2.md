## Added

- A **Keep canvas filled** option updates Scale automatically as Width or Height changes, without forcing this behavior on users who prefer manual framing.
- **Compare** shows the untouched source beside the actual converted output on desktop, with an Original/Converted switch on smaller screens.
- The editor now displays the original and converted formats and file sizes together, including the percentage saved or added.
- A GitHub link with the GitHub mark is now available directly in the app header.

## Changed

- A cleaner, denser interface makes controls and supporting text easier to read while preserving distinct Discord, 7TV, and Twitch colors.
- The Canvas and chat Preview playback buttons now control their animations independently.
- The selected section of an animation timeline can be dragged as one range instead of moving each edge separately.
- Discord and Twitch animation selections now adapt in both speed directions: slowing trims frames to remain within five seconds, while speeding restores eligible frames toward the limit.
- Animated AVIF and GIF conversions preserve smoother motion where the size limit permits and favor palette optimization before removing more frames.
- Trackpad zoom is less sensitive during slow movement and applies proportionally larger changes during faster gestures. Conventional mouse-wheel steps still change Scale by one percentage point.

## Fixed

- 7TV exports now stay strictly below the service's 3:1 aspect-ratio limit. Extra-wide or extra-tall artwork is fitted inside a compatible transparent canvas instead of producing a rejected upload.
- The version number now opens the repository changelog directly.

## Documentation

- The README now leads with the hosted editor, explains the current workflow, and includes an updated product screenshot.

## Notes

- Package version: `1.2.0`; Git tag: `v1.2`.
- No configuration changes or migration steps are required.
