## Added

- The header now shows the exact Emote Workshop version and links directly to its matching GitHub Release, making it easier to identify and review the installed build.

## Changed

- Smooth trackpad scrolling now accumulates small movements before changing Scale, preventing tiny wheel events from zooming too quickly. A regular mouse-wheel step still changes Scale by one percentage point.

## Fixed

- Twitch exports now stay within the current manual-upload requirements: static PNG files are limited to 100 KB, while animated GIF files are limited to 512 KB and 60 frames.
- Very long 7TV animations now preserve their intended GIF timing instead of wrapping oversized frame delays.

## Security

- Added bounded animation processing: oversized render plans are sampled before output-frame allocation, while MP4 handoff rejects excessive decoded frames, dimensions, total pixels, or invalid timing metadata.

## Notes

- Package version: `1.1.1`; Git tag: `v1.1.1`.
- No configuration changes or migration steps are required.
