# Emote Workshop 1.5

## Added

- Hover over Scale, Width, Height, Brightness, or Playback speed and scroll to adjust by one percentage point per mouse-wheel notch. Scroll up to move the slider right and increase its value; scroll down to move it left and decrease its value.
- Rotation and Outline support the same interaction, changing by 1° and 0.5 px respectively.
- Trackpad scrolling accumulates into small steps and responds proportionally to faster gestures, using the same sensitivity as canvas zoom. Slider values stay within their limits, and scrolling over an active slider keeps the page in place.

Changes update the live preview and work with undo/redo, each destination's settings, and **Keep canvas filled**.

Package version: `1.5.0`; Git tag: `v1.5`.

[Source code for this release](https://github.com/Gimbuhh/Emote-Workshop/tree/v1.5).
